# Job Finder - AI-Powered Job Application Assistant

A production-ready, lightweight multi-user AI system for automating job applications with human-in-the-loop approval via Telegram.

## Features ✨

- **User Authentication**: Secure JWT-based auth with bcrypt password hashing
- **Job Matching**: AI-powered job matching using Groq API (Mixtral/Llama2)
- **Resume & Cover Letter Generation**: Tailored documents generated by AI
- **Automated Form Filling**: Playwright-based automation with typing simulation
- **Telegram Approval**: Pause before submission, get user approval via Telegram Bot
- **Job Filtering**: Pre-filter jobs based on user preferences
- **Dashboard**: Job listings, application tracking, preferences management
- **Multi-User**: Fully user-scoped data with MongoDB
- **Lightweight**: Minimal dependencies, optimized for performance

## Tech Stack

**Backend:**
- FastAPI (Python)
- MongoDB (Database)
- Motor (Async MongoDB driver)
- Groq API (AI Matching & Generation)
- Playwright (Automation)
- JWT + bcrypt (Authentication)
- python-telegram-bot (Notifications)

**Frontend:**
- React 18 (UI)
- Vite (Bundler)
- React Router (Navigation)
- Axios (API calls)
- CSS3 (Styling)

## Quick Start

### Prerequisites
- Python 3.9+
- Node.js 16+
- MongoDB (local or cloud)
- Groq API key
- Telegram Bot Token

### Backend Setup

1. **Clone and setup**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

2. **Configure environment**
```bash
cp .env.example .env
# Edit .env with your credentials:
# - MONGODB_URL
# - GROQ_API_KEY
# - TELEGRAM_BOT_TOKEN
# - JWT_SECRET_KEY
```

3. **Run backend**
```bash
python -m app.main
# Or use: uvicorn app.main:app --reload
```

Backend will be available at `http://localhost:8000`
API docs: `http://localhost:8000/docs`

### Frontend Setup

1. **Install dependencies**
```bash
cd frontend
npm install
```

2. **Run frontend**
```bash
npm run dev
```

Frontend will be available at `http://localhost:5173`

3. **Build for production**
```bash
npm run build
```

## API Endpoints

### Authentication
- `POST /auth/register` - Register new user
- `POST /auth/login` - Login user
- `GET /auth/me` - Get current user

### Jobs
- `POST /jobs` - Create job
- `GET /jobs` - Get user's jobs
- `GET /jobs/{job_id}` - Get job details
- `POST /jobs/{job_id}/match` - Analyze job match
- `POST /jobs/{job_id}/generate-resume` - Generate tailored resume
- `POST /jobs/{job_id}/generate-cover-letter` - Generate cover letter
- `GET /jobs/filter-by-preferences` - Get jobs matching preferences

### Applications
- `POST /applications/{job_id}/submit` - Create pending application
- `GET /applications` - Get user's applications
- `GET /applications/{app_id}` - Get application details
- `POST /applications/{app_id}/approve` - Approve application
- `POST /applications/{app_id}/reject` - Reject application

### Preferences
- `GET /preferences` - Get user preferences
- `PUT /preferences` - Update user preferences

## Workflow

1. **User Registration**
   - Create account and add Telegram Chat ID
   - System creates default user preferences

2. **Add Jobs**
   - Manually add jobs or integrate with job boards (Indeed, Naukri, etc.)
   - Jobs stored per user

3. **Match Jobs**
   - Click "Analyze Match" to get AI-powered job matching
   - Groq API analyzes match score, missing skills, strengths

4. **Generate Documents**
   - Generate tailored resume for job
   - Generate cover letter
   - Review and edit if needed

5. **Submit Application**
   - Submit application (stored as pending)
   - Telegram bot sends approval request to user

6. **Telegram Approval**
   - User reviews notification on Telegram
   - Click "Approve" or "Reject"
   - If approved, Playwright fills form and submits
   - Application marked as "Applied"

7. **Track Applications**
   - View all applications in dashboard
   - Filter by status: Pending, Applied, Rejected

## Security Considerations

1. **Password Hashing**: Uses bcrypt with salt
2. **JWT Authentication**: Secure token-based auth
3. **Database Indexes**: Optimized for query performance
4. **Rate Limiting**: Consider adding in production
5. **CORS**: Configure allowed origins in production
6. **Environment Variables**: Never commit .env files
7. **API Validation**: Pydantic schema validation
8. **HTTPS**: Use in production

## Best Practices

1. **Bot Detection Avoidance**
   - Playwright uses headless browser
   - Typing simulation with delays
   - Random wait times between actions
   - Realistic user-agent headers

2. **Async Operations**
   - All database operations are async
   - Non-blocking API calls
   - Efficient resource usage

3. **Error Handling**
   - Comprehensive error messages
   - Graceful fallbacks
   - Logging for debugging

4. **Code Organization**
   - Modular architecture
   - Separation of concerns
   - Easy to extend and maintain
